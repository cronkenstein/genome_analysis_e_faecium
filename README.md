# Welcome to Aleksander Cronk's Genome Analysis of E. Faecium!
This project is a an analysis of RNA Seq of vancomycin resistant Enterococcus Faecium to determine the commensal strain's differential gene expression for Uppsala Universitet Genome Analysis Project.

For all the SBATCH scripts, look under the `analyses` directory.

For all the results referred to by the Wiki, look under the `results` directory.

Get started by heading on over to the [Wiki](https://github.com/cronkenstein/genome_analysis_e_faecium/wiki)
